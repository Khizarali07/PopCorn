# usePopcorn (Course project)

A lightweight movie search & watchlist demo showcasing fetching, controlled inputs and list management in React.

## Key features

- Search movies (mock / API)
- Add to watchlist and manage entries
- Simple routing for details/watchlist

## Tech

- React (Create React App)
- CSS for layout and styling

## Run locally

1. Install dependencies: `npm install`
2. Start dev server: `npm start`

## Notes

- If the project uses an external movie API, ensure you have an API key and update the fetch calls accordingly.
